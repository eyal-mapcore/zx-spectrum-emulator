ZX Spectrum 48K → PC Keyboard Map

All 40 Spectrum keys map one-to-one onto a standard 104/105-key PC keyboard. Legends below are extracted from the 48K ROM's own key tables, so they match what the machine actually produces — not what is silk-screened on any particular case.

Matrix Wiring & Shifted Combinations

The keyboard is an 8×5 matrix read through the ULA. Any port with bit 0 clear selects it; the high byte of the port chooses which rows to scan. Rows are active low, and several may be selected at once, in which case their results are ANDed — that is how the ROM detects a shifted key. A pressed key reads back as 0.

Matrix map

Rows 3 and 4 run in opposite directions. Row 3 counts 1 2 3 4 5 outward from the left edge of the keyboard and row 4 counts 0 9 8 7 6 outward from the right, mirroring the physical wiring. This is a classic source of transposed-key bugs.

Shifted combinations a PC user expects

The Spectrum has no dedicated Backspace, cursor, comma or period keys — they are all SHIFT combinations. To support the PC keys below, one scancode must pull two matrix bits low.

On the digit keys, extended mode sets a colour, not a keyword. EXTENDED then a letter gives that letter's keyword, but EXTENDED then a digit inserts a colour change into the line: digits 0–7 set the PAPER of the text that follows, or its INK with CAPS SHIFT; 8 and 9 give BRIGHT 0/1, or FLASH 0/1 with CAPS SHIFT. Inside a PRINT string that colours individual words. The digit keywords (DEF FN, LINE, FORMAT…) need EXTENDED + SYM SHIFT + digit, and the colour keywords themselves are on letters: INK X, PAPER C, FLASH V, BRIGHT B, INVERSE M, OVER N (each EXTENDED + SYM SHIFT), TAB P (EXTENDED) and AT I (SYM SHIFT alone).
This is a positional map, not a character map. Shift+2 prints @ on a PC, but CAPS SHIFT + 2 on a Spectrum is CAPS LOCK — @ is SYM SHIFT + 2. Mapping physical positions keeps the emulator faithful; a "PC-friendly" typing mode is a separate translation layer.
Legends extracted from 48.rom: token table 0x0095; SYM SHIFT letters 0x026A; EXTENDED letters 0x022C; EXTENDED+SYM letters 0x0246; CAPS SHIFT digits 0x0260; EXTENDED + SYM digits 0x0284. K-mode keywords are token 0xE6 + (letter − 'A'), computed rather than tabulated. EXTENDED digits are decoded by SUB $20 / SUB $36 at 0x037B and then turned into PAPER/INK/BRIGHT/FLASH by the editor — verified by printing text after each combination and reading back its attribute. SYM SHIFT digit symbols and every extended-mode path verified by running the ROM and reading LAST-K (0x5C08). Matrix assignments mirror include/z80/keyb_lookup.h.
